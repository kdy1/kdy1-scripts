# Write Marketing Copy

Rephrase the material the user provides into three publication-ready social posts: one each for LinkedIn, X, and Threads. Express the same core message independently for each platform instead of translating one version literally into the others. Always produce all three posts. Do not publish them.

## Rephrase the source

- Treat the user's material as the source of truth and preserve its core message, point of view, and intent.
- Rewrite rather than reuse the source wording. Improve clarity, flow, naturalness, and platform fit in each version.
- Preserve names, links, numbers, and factual claims accurately.
- Do not invent facts, testimonials, customer results, or product capabilities.
- Do not add new ideas, calls to action, or hashtags unless requested or already present in the source.
- Even when the source is already written for one social platform, rephrase it separately for all three platforms.
- Proceed when the subject and intent are reasonably clear. Ask a question only when the core message cannot be inferred.
- Follow explicit requests for voice, length, or format while still returning all three platforms.

## Default voice

Write in a credible first-person expert voice: clear, specific, confident, and human. Avoid hype, generic marketing language, and unsupported superlatives. Use emojis only when requested. When the source includes a call to action or hashtags, rephrase or adapt them to fit each platform.

## Platform copy

### LinkedIn

Write in English. Open with a strong, credible lead, then develop the idea in short, readable paragraphs. Include enough context for the post to stand alone.

### X

Write in English. Prefer one post of no more than 280 characters. If that would remove essential meaning, write a thread of two to four posts; keep every post within 280 characters and number them as `1/N`, `2/N`, and so on.

### Threads

Write in natural Korean using consistent formal polite endings such as `-합니다` and `-입니다`. Favor idiomatic Korean social writing over English-derived sentence structure.

## Output

Always return all three sections in this order:

1. `LinkedIn`
2. `X`
3. `Threads`

Put each ready-to-post copy in its own fenced code block, with the label outside the block. Do not add a language identifier to the fence. If X requires a thread, put each numbered post in a separate fenced code block so it can be copied independently.

Return only the labels and ready-to-post copy. Do not add strategy notes, explanations, or alternative drafts unless requested.
