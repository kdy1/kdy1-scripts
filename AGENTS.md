# Repository Guidelines

## Git commits

- Commit frequently while working. Create a commit after each coherent, verified unit of work instead of accumulating unrelated changes in a single commit.

## Skill implementation

- For every skill, extract operations worth scripting into reusable scripts. This includes repetitive commands, deterministic processing, validation, and error-prone multi-step operations.
- Keep judgment, user interaction, and workflow guidance in `SKILL.md`. Document when and how to run the scripts.
- Apply this rule when creating or modifying any skill. Reuse existing helpers where appropriate.
